# Wetter-Widget

24-Stunden-Wettergrafik im Stil des eingestellten Android-Widgets *AixWeather*: Temperatur (echt und gefühlt), Niederschlag, Wolken, Wind, UV-Index, Wettersymbole, Sonne, Mond und – am Meer – Tide.

**Live:** https://jungundeck.github.io/wetter-widget/

Eine einzelne HTML-Datei ohne Server und ohne API-Key. Ort per Suche oder GPS wählbar; Ort und Anzeige-Einstellungen werden nur lokal im Browser gespeichert.

Wetterdaten: [Open-Meteo.com](https://open-meteo.com) (CC BY 4.0) · Mondberechnung nach [SunCalc](https://github.com/mourner/suncalc) (BSD) · Ortsname bei GPS: BigDataCloud
